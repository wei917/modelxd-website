# ModelXD XDuel UI (Standalone)

This is a **standalone Next.js App Router** project that previews the ModelXD XDuel UI **without shadcn/ui** (so it runs out-of-the-box).

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Notes
- This UI uses placeholder outputs + placeholder cost calculations.
- Hook it to Supabase later by replacing `demoXDuel()` with real calls and persisting xduels/votes.
